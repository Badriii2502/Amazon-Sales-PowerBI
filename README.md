\# Amazon Sales Analytics Dashboard



An interactive sales analytics dashboard developed using Python and Microsoft Power BI. The project demonstrates data cleaning, ETL, business analysis, DAX measures, interactive reporting and row-level security.



\## Project Overview



The project uses the Kaggle Amazon Sales Dataset and transforms the raw sales data using Python before loading the processed dataset into Power BI.



The dashboard provides insights into:



\- Overall sales performance

\- Monthly sales trends

\- Product category performance

\- Brand performance

\- Order value distribution

\- Customer activity

\- Payment methods

\- Shipping costs

\- Order details

\- Regional and user-based data access



\## Tech Stack



\- Python

\- Pandas

\- Microsoft Power BI

\- DAX

\- Power Query

\- CSV



\## Dataset



Source: Kaggle Amazon Sales Dataset



The original dataset contains 100,000 sales records and 20 fields.



The dataset was processed using Python and expanded to 30 fields containing both original and derived business attributes.



\## Python ETL



The ETL process was implemented using Pandas.



\### ETL Operations



\- Loaded the raw CSV dataset

\- Converted order dates into datetime format

\- Cleaned text fields

\- Converted monetary values from USD to INR

\- Calculated gross sales amount

\- Calculated discount amount

\- Calculated net sales amount

\- Extracted year, month, quarter and day information

\- Created order value bands

\- Generated the final processed CSV dataset



\### Derived Fields



Some of the additional fields created during ETL include:



\- GrossAmount

\- DiscountAmount

\- NetSalesAmount

\- OrderYear

\- OrderMonth

\- OrderMonthName

\- OrderQuarter

\- OrderDayOfWeek

\- OrderDayNumber

\- OrderValueBand



\## Power BI Dashboard



The Power BI report contains the following pages:



\### 1. Home



Provides navigation to the main dashboard sections and highlights the purpose of the project.



\### 2. Sales Performance Overview



Provides high-level KPIs and sales trends.



Key metrics include:



\- Total Sales

\- Total Orders

\- Units Sold

\- Average Order Value

\- Discount Amount



\### 3. Sales Analysis



Focuses on product and category performance.



Visuals include:



\- Sales by Category

\- Brand Sales Distribution

\- Sales by Order Value

\- Monthly Sales vs Discount



\### 4. Order \& Customer Insights



Analyses customer activity and order behaviour.



Includes:



\- Total Customers

\- Average Order Value

\- Average Units per Order

\- Shipping Cost

\- Top Customers

\- Top Cities

\- Payment Method and Order Status analysis



\### 5. Processed Sales Data



Displays the processed dataset generated by the Python ETL pipeline.



The final dataset contains:



\- 100,000 records

\- 30 fields



\### 6. Order Details



A dedicated drill-through page providing detailed transaction-level information for the selected context.



\## Power BI Features



The dashboard uses several Power BI capabilities:



\- DAX measures

\- Interactive slicers

\- Drill-through

\- Page navigation

\- Bookmarks

\- Dynamic currency formatting

\- Indian number formatting

\- Row-level security

\- Interactive filtering

\- KPI cards

\- Time-based analysis



\## Row-Level Security



The project also demonstrates Row-Level Security (RLS) using user-based regional access.



A separate access table maps users to permitted states, and DAX with `USERPRINCIPALNAME()` is used to determine the appropriate data access.
